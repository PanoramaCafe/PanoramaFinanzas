# Panorama Finanzas — GitHub Pages

1. Subir estos archivos a la raíz del repositorio.
2. GitHub → Settings → Pages.
3. Source: Deploy from a branch.
4. Branch: `main`.
5. Folder: `/ (root)`.
6. Guardar y abrir la URL de GitHub Pages.

La app usa almacenamiento local del navegador; GitHub Pages publica el código pero no sincroniza automáticamente los datos entre dispositivos.
